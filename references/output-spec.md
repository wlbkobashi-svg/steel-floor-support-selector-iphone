# 結果画像仕様

画像出力を求められたときに読む。

- 縦長、白地、濃紺の見出し、青緑の推奨強調。
- 上部: `GTフロアー 支持台・ボルト選定結果` または `GTダイレクト 支持台・ボルト選定結果`。
- 現場名と床用途、保存日時（出力直前の日本時間）を表示。
- 推奨候補を最大の文字で表示し、直下に公式調整範囲を表示。
- 入力条件、根太上高さへの計算、適合候補上位3件を読みやすく配置。
- 断面構成の画像は入れない。
- 下部の一般的な注意書き欄は入れない。
- KIRIIの表示は、公式またはユーザー提供のロゴ資産がある場合のみその資産を使う。資産がない場合は `KIRII` の文字表示に留め、ロゴ形状を創作しない。
- ファイル名: `<現場名>_<製品名>_支持台ボルト選定_YYYYMMDD_HHmm.svg`。危険なファイル名文字は `_` に置換する。

SVGはそのまま画像として渡せる。PNG指定時は、利用可能なSVGレンダラーまたはブラウザのスクリーンショットでPNG化し、文字欠け・重なり・余白を目視確認する。
